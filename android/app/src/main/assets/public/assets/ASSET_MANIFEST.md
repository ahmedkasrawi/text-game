# فهرس الأصول البصرية المنظمة — لعبة «الظل التاه» (`assets/`)

> تم إنشاء هذه البنية في **الخطوة 1** تمهيداً لتنظيف/توحيد الصور في **الخطوة 2**. مجلد [`متجر/`](../متجر) الأصلي باقٍ كما هو كمرجع أولي حتى اكتمال المعالجة في الخطوة 2.

---

## 1. خريطة مجلدات `assets/`

| المسار | الغرض | الأسلوب المطلوب في الخطوة 2 |
| :--- | :--- | :--- |
| `assets/scenes/` | خلفيات المدن والمشاهد (العاصمة، الثغر، الميناء، الأزقة، الدير، ساحة المعركة، الورشة/الملاذ، البداية) | 8 مشاهد أفقية (`16:9` أو عريضة) بأسلوب Dark Gritty Medieval Oil |
| `assets/characters/` | بورتريهات طاقم الشخصيات الرئيسي (6–8 شخصيات) + شخصيات عابرة + صورة البطل | بورتريهات رأس/كتف موحّدة الإضاءة والإطار |
| `assets/items/weapons/swords/` | سيوف المتجر والندرة المتدرجة | خلفيات شفافة حقيقية (`PNG/WebP`) دون علامات مائية |
| `assets/items/weapons/axes/` | فؤوس كسر الدروع | خلفيات شفافة حقيقية دون شطرنج مطبوع |
| `assets/items/weapons/spears/` | رماح الصد والمدى | خلفيات شفافة حقيقية دون شطرنج مطبوع |
| `assets/items/weapons/bows/` | أقواس الضربة الاستباقية | خلفيات شفافة حقيقية دون شطرنج مطبوع |
| `assets/items/armors/` | أزياء ودروع (عباءات ظل، دروع حديدية، أردية تجار وكنيسة) | خلفيات شفافة حقيقية موحّدة الطابع |
| `assets/items/potions/` | جرعات العلاج والسموم والمنشطات التكتيكية | خلفيات شفافة حقيقية موحّدة النمط |
| `assets/items/accessories/` | تمائم، أختام، وخواتم عائلية وفصائلية | أيقونات/صور واضحة بألوان الندرة |
| `assets/ui/` | شعار اللعبة، خريطة القارة المصغّرة، وأيقونات الفصائل الأربع والندوب | أصول واجهة خفيفة ونظيفة |
